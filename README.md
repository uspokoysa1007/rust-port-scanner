# ⚡ rust-port-scanner

[![Rust](https://img.shields.io/badge/Language-Rust%202021-orange.svg)](https://www.rust-lang.org/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)]()

> Высокопроизводительный асинхронный сканер TCP-портов и сетевых служб на Rust, построенный на базе рантайма **Tokio** и **Futures**.

```text
==============================================
       ⚡ RUST ASYNC PORT SCANNER ⚡          
==============================================
🎯 Цель:         127.0.0.1
🔢 Диапазон:     1-1024
🚀 Потоков:      200
⏱ Таймаут:      800 ms
----------------------------------------------
🌐 IP-адрес:     127.0.0.1
⏳ Сканирование запущено...

  [+] Порт 135   ОТКРЫТ  (5 ms) -> Unknown
  [+] Порт 445   ОТКРЫТ  (5 ms) -> SMB

----------------------------------------------
📊 РЕЗУЛЬТАТЫ СКАНИРОВАНИЯ:
  Всего проверено: 1024 портов
  Открытых портов: 2
  Затраченное время: 4.15 сек
```

## ✨ Возможности
- ⚡ **Асинхронный движок (Tokio):** проверка сотен и тысяч портов одновременно без создания тяжелых системных потоков ОС.
- 🎯 **Гибкая цель:** поддержка доменных имен (`example.com`, `scanme.nmap.org`) и прямых IPv4-адресов.
- 🔍 **Автоматическое распознавание сервисов:** мгновенно определяет протоколы (HTTP, HTTPS, SSH, FTP, SMB, RDP, MySQL, PostgreSQL, Redis, DNS и др.).
- 📡 **Измерение задержки (Latency):** фиксирует время отклика в миллисекундах для каждого обнаруженного сервиса.
- ⚙️ **Тонкая настройка:** управление числом параллельных запросов (`-c`) и таймаутом ожидания (`-t`).
- 🎨 **Красивый цветной терминальный вывод.**

## 🚀 Быстрый старт

### 1. Готовый бинарник
Скачайте архив из раздела [Releases] или используйте готовый файл из папки `release-package/`:
```powershell
.\rust-port-scanner.exe --help
```

### 2. Сборка из исходников
```powershell
git clone <URL_РЕПОЗИТОРИЯ>
cd rust-port-scanner
cargo run --release -- --help
```

## 📖 Примеры использования

```powershell
# 1. Быстрое сканирование локального хоста (порты 1-1024)
.\rust-port-scanner.exe --target 127.0.0.1

# 2. Сканирование веб-сервера по доменному имени
.\rust-port-scanner.exe --target scanme.nmap.org -s 20 -e 100

# 3. Высокоскоростное сканирование (500 конкурентных потоков)
.\rust-port-scanner.exe --target 192.168.1.1 -s 1 -e 10000 -c 500

# 4. Сканирование с уменьшенным таймаутом (200 мс) для быстрой локальной сети
.\rust-port-scanner.exe --target 127.0.0.1 -s 1 -e 5000 -t 200
```

## 🛠 Параметры командной строки
| Флаг | Полное имя | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `-t` | `--target` | `127.0.0.1` | IP-адрес или доменное имя цели |
| `-s` | `--start-port` | `1` | Начальный номер порта |
| `-e` | `--end-port` | `1024` | Конечный номер порта |
| `-c` | `--concurrency`| `200` | Число параллельных асинхронных проверок |
| | `--timeout-ms` | `800` | Таймаут ожидания соединения в миллисекундах |
| `-h` | `--help` | | Справка по всем доступным опциям |
| `-V` | `--version` | | Показать текущую версию утилиты |
